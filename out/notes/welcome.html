Welcome to Nitin's Desk

May 12, 2026·2 min read·Snippets

How this corner of the site works, what to expect, and a tour of the markdown features it supports.

This is Nitin's Desk — a quiet place where I write down things I'm learning. No newsletter, no algorithm, no analytics. Just markdown files in a folder that turn into pages.

How it works#

Every note in this section is a single .mdx file under content/notes/. I write locally, commit, and GitHub Actions rebuilds the site. New file → new page.

Posts are tagged by intent rather than topic:

  • Foundations — first-principles explanations I'd want to re-read in a year.
  • Internals — how something actually works under the hood.
  • Snippets — short notes. A trick, a gotcha, a one-page insight.
  • Readings — paper, book, and talk notes.
  • Playbooks — repeatable how-tos and checklists.
  • Lab — experiments and tinkering that may not pan out.
