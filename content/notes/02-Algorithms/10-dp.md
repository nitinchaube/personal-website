## **1D DP**

### Problem 1: Fibonacci Numbers

([http://leetcode.com/problems/fibonacci-number/description/](http://leetcode.com/problems/fibonacci-number/description/))

**Recursion tree** (example: `fib(5)`):

```
                        fib(5)
                       /      \
                  fib(4)      fib(3)  ← repeated
                 /     \       /    \
            fib(3)   fib(2) fib(2) fib(1)
            /   \     /  \    ↑
       fib(2) fib(1) ...  ...  same subproblems
       /  \
  fib(1) fib(0)
```

```python
class FibonacciSolutions:
    # SOLUTION 1: Top-Down DP (Memoization)
    # Time: O(n) | Space: O(n) [Array + Call Stack]
    def fib_top_down(self, n: int) -> int:
        # Create a cache to store already calculated values
        dp = [-1] * (n + 1)
        
        def find_fib(a: int) -> int:
            if a <= 1:
                return a
            # If we already calculated it, return it immediately
            if dp[a] != -1:
                return dp[a]
            
            # Save the result in the cache before returning
            dp[a] = find_fib(a - 1) + find_fib(a - 2)
            return dp[a]
            
        return find_fib(n)

    # SOLUTION 2: Bottom-Up DP (Tabulation)
    # Time: O(n) | Space: O(n) [Array only, no recursion]

    def fib_bottom_up(self, n: int) -> int:
        if n <= 1:
            return n
            
        # Build the table from the ground up
        dp = [-1] * (n + 1)
        dp[0] = 0
        dp[1] = 1
        
        # Fill the table iteratively
        for i in range(2, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]
            
        return dp[n]


    # SOLUTION 3: Bottom-Up DP (2-Variable / Space Optimized)
    # Time: O(n) | Space: O(1) [Constant memory]

    def fib_bottom_up_optimized(self, n: int) -> int:
        if n <= 1:
            return n
        # Instead of an array, we only keep track of the last two numbers
        prev2 = 0
        prev1 = 1
        for i in range(2, n + 1):
            cur = prev2 + prev1
            # Slide the window forward
            prev2 = prev1
            prev1 = cur      
        return prev1
```

### Problem 2: Frog Jump

[https://takeuforward.org/plus/dsa/problems/frog-jump?utm=codolio](https://takeuforward.org/plus/dsa/problems/frog-jump?utm=codolio)

**Recursion tree** (example: `f(i)` = min cost to reach index `i`, target `f(3)`):

```
                         f(3)
                        /    \
           f(2)+|h3-h2|      f(1)+|h3-h1|
              /    \              |
         f(1)+...  f(0)→0      f(0)→0
        /    \
   f(0)→0  (stop)

        ↑ f(1) and f(2) get recomputed in other branches → DP
```

Frog starts at index `0`, must reach `n-1`. From `i` it can jump to `i+1` or `i+2`; cost of a jump is `|heights[j] - heights[i]|`. Find minimum total cost.

Recurrence: `dp[i] = min(dp[i-1] + |h[i]-h[i-1]|, dp[i-2] + |h[i]-h[i-2]|)` with `dp[0] = 0`.

```python
## SOLUTION 1: Recursion
# Time: O(2^n) | Space: O(n) — overlapping subproblems recomputed each call
class Solution:

    def recursion(self, ind, heights):
        if ind == 0: return 0  # base case: at start, cost is 0
        # 1-step jump from (ind - 1)
        left = self.recursion(ind - 1, heights) + abs(heights[ind] - heights[ind - 1])
        # 2-step jump from (ind - 2), only if valid
        right = float("inf")
        if ind > 1:
            right = self.recursion(ind - 2, heights) + abs(heights[ind] - heights[ind - 2])
        return min(left, right)  # min cost to reach index `ind`

    def frogJump(self, heights):
        n = len(heights)
        return self.recursion(n - 1, heights)

## SOLUTION 2: Time optimized using DP
# Time: O(n) | Space: O(n) — tabulate min cost to each index
class Solution:

    def frogJump(self, heights):
        n = len(heights)
        dp = [0] * n  # dp[i] = min cost to reach index i
        for i in range(1, n):
            fs = dp[i - 1] + abs(heights[i] - heights[i - 1])  # 1-step jump
            ss = float("inf")
            if i > 1:
                ss = dp[i - 2] + abs(heights[i] - heights[i - 2])  # 2-step jump
            dp[i] = min(fs, ss)

        return dp[-1]

## SOLUTION 3: Space optimized in DP
# Time: O(n) | Space: O(1) — only need last two dp values
class Solution:
    def frogJump(self, heights):
        n = len(heights)
        prev = 0   # dp[i - 1]
        prev2 = 0  # dp[i - 2]
        for i in range(1, n):
            fs = prev + abs(heights[i] - heights[i - 1])
            ss = float("inf")
            if i > 1:
                ss = prev2 + abs(heights[i] - heights[i - 2])
            curr = min(fs, ss)
            prev2 = prev  # slide window forward
            prev = curr

        return prev
```

### Problem 3: Frog Jump with K Distances

[https://takeuforward.org/plus/dsa/problems/frog-jump-with-k-distances?utm=codolio](https://takeuforward.org/plus/dsa/problems/frog-jump-with-k-distances?utm=codolio)

**Recursion tree** (example: `k=3`, `f(4)` = min cost to reach index `4`):

```
                              f(4)
                    /         |         \
         f(3)+|h4-h3|   f(2)+|h4-h2|   f(1)+|h4-h1|
           / | \           / | \            |
     f(2) f(1) f(0)    f(1) f(0) ...     f(0)→0
      ↑ up to k branches at every node; subproblems overlap → memo
```

Same as Frog Jump, but the frog can jump `1` to `k` steps at a time. Find minimum total energy.

Recurrence: `dp[i] = min(dp[i-j] + |h[i]-h[i-j]|)` for `j` in `1..k` where `i-j >= 0`, with `dp[0] = 0`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n*k) | Space: O(n) — memo avoids recomputing subproblems
class Solution:
    def recursion(self, ind, heights, k, memo):
        if ind == 0: return 0  # base case: at start, cost is 0
        if memo[ind] != -1:
            return memo[ind]  # return cached result

        min_energy = float("inf")
        # try all jump sizes from 1 to k
        for j in range(1, k + 1):
            if ind - j >= 0:
                jump = self.recursion(ind - j, heights, k, memo) + abs(heights[ind] - heights[ind - j])
                min_energy = min(min_energy, jump)

        memo[ind] = min_energy
        return min_energy

    def frogJump(self, heights, k):
        n = len(heights)
        memo = [-1] * n
        return self.recursion(n - 1, heights, k, memo)

## SOLUTION 2: Time optimized using DP
# Time: O(n*k) | Space: O(n) — tabulate min cost to each index
class Solution:
    def frogJump(self, heights, k):
        n = len(heights)
        if n == 0:
            return 0

        dp = [0] * n  # dp[i] = min cost to reach index i
        for i in range(1, n):
            min_energy = float("inf")
            # check all previous steps within jump range k
            for j in range(1, k + 1):
                if i - j >= 0:
                    jump = dp[i - j] + abs(heights[i] - heights[i - j])
                    min_energy = min(min_energy, jump)
            dp[i] = min_energy

        return dp[n - 1]

## SOLUTION 3: Space optimized in DP
# Time: O(n*k) | Space: O(k) — sliding window keeps only last k costs
class Solution:
    def frogJump(self, heights, k):
        n = len(heights)
        if n == 0:
            return 0

        dp = [0]  # window: dp[-j] = cost of stair (i - j)
        for i in range(1, n):
            min_energy = float("inf")
            for j in range(1, k + 1):
                if i - j >= 0:
                    jump = dp[-j] + abs(heights[i] - heights[i - j])
                    min_energy = min(min_energy, jump)

            dp.append(min_energy)
            if len(dp) > k:
                dp.pop(0)  # drop oldest when window exceeds k

        return dp[-1]
```

### Problem 4: Maximum Sum of Non-Adjacent Elements

[https://leetcode.com/problems/house-robber/description/?utm=codolio](https://leetcode.com/problems/house-robber/description/?utm=codolio) — LC 198: House Robber

**Recursion tree** (example: `f(i)` = max sum robbing houses `0..i`, target `f(3)`):

```
                              f(3)
                             /    \
               pick: n[3]+f(1)    skip: f(2)
                    /    \           /    \
              pick n[1]+f(-1)  skip f(0)  pick n[2]+f(0)  skip f(1)
                    ↓              ↓           ↓              ↓
                   0            n[0]         n[0]         pick/skip...
                    ↑ f(1) reached from two paths → memo
```

Pick a subset of elements with **maximum sum** such that no two chosen elements are adjacent.

Recurrence: `dp[i] = max(nums[i] + dp[i-2], dp[i-1])` with `dp[0] = nums[0]`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n) | Space: O(n) — memo avoids recomputing subproblems
class Solution:
    def recurse(self, ind, nums, dp):
        if dp[ind] != -1:
            return dp[ind]  # return cached result
        if ind < 0:
            return 0  # no houses left
        if ind == 0:
            return nums[0]  # only one house to rob
        pick = nums[ind] + self.recurse(ind - 2, nums, dp)      # rob current house
        not_pick = self.recurse(ind - 1, nums, dp)              # skip current house
        dp[ind] = max(pick, not_pick)
        return dp[ind]

    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [-1] * n
        return self.recurse(n - 1, nums, dp)

## SOLUTION 2: Time optimized using DP
# Time: O(n) | Space: O(n) — tabulate max sum up to each index
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0] * n  # dp[i] = max sum robbing houses 0..i
        dp[0] = nums[0]
        for i in range(1, n):
            take = nums[i]
            if i > 1:
                take += dp[i - 2]  # rob house i + best up to i-2
            non_take = dp[i - 1]   # skip house i
            dp[i] = max(take, non_take)
        return dp[n - 1]

## SOLUTION 3: Space optimized in DP
# Time: O(n) | Space: O(1) — only need last two dp values
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        prev2 = 0          # dp[i - 2]
        prev = nums[0]     # dp[i - 1]
        for i in range(1, n):
            take = nums[i]
            if i > 1:
                take += prev2
            non_take = prev
            curr = max(take, non_take)
            prev2 = prev  # slide window forward
            prev = curr
        return prev
```

### Problem 4.2: House Robber 2

[https://leetcode.com/problems/house-robber-ii/](https://leetcode.com/problems/house-robber-ii/)

**Recursion tree** — circular array splits into two linear House Robber subproblems:

```
rob([h0, h1, h2, h3])   first and last house are adjacent
         |
    ┌────┴────┐
solve(0→2)  solve(1→3)   exclude last OR exclude first
    |           |
  f(2) tree   f(2) tree   same pick/skip tree as Problem 4
    |           |
  max sum     max sum

Answer = max(solve(0, n-2), solve(1, n-1))
```

```python
from typing import List

class Solution:
    def solve(self, nums: List[int], start: int, end: int) -> int:
        prev, prev2 = 0, 0
        
        # Iterate only through the specified indices
        for i in range(start, end + 1):
            # take: rob current house + money from 2 houses back
            # non_take: keep the money from the previous house
            curr = max(nums[i] + prev2, prev)
            
            # Shift variables forward for the next iteration
            prev2 = prev
            prev = curr
            
        return prev

    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        
        # Edge cases
        if n == 0: return 0
        if n == 1: return nums[0]
        
        # Option 1: Rob from house 0 to n-2 (exclude last house)
        # Option 2: Rob from house 1 to n-1 (exclude first house)
        return max(
            self.solve(nums, 0, n - 2), 
            self.solve(nums, 1, n - 1)
        )
```

## 2D/3D DP and DP on grids

### Problem 1: Ninjas Training

[https://takeuforward.org/plus/dsa/problems/ninja's-training?utm=codolio](https://takeuforward.org/plus/dsa/problems/ninja's-training?utm=codolio)

**Recursion tree** (example: `f(day, last)` = max points; `last` = task done yesterday, `3` = no restriction):

```
                    f(2, last=3)
                   /      |      \
        pts+ f(1,0)  pts+ f(1,1)  pts+ f(1,2)
              |           |           |
         f(0,·) tree  f(0,·) tree  f(0,·) tree
              ↑ each node picks a task ≠ last; (day, last) states repeat → 2D DP
```

```python
### SOLUTION 1: Recursion + DP
class Solution:
    def f(self, day, last , points, dp):
        if day==0:
            maximum = 0
            for task in range(3):
                if task!=last:
                    maximum = max(maximum, points[0][task]) 
            return maximum
        
        if dp[day][last]!=-1:
            return dp[day][last]

        
        maximum = 0
        for task in range(3):
            if task!= last:
                point = points[day][task] + self.f(day-1, task, points, dp)
                maximum = max(point, maximum)
        dp[day][last] = maximum
        return dp[day][last]


    def ninjaTraining(self, matrix):
        m = len(matrix)
        n = len(matrix[0])

        dp  = [[-1 for i in range(4)] for _ in range(m)]
        return self.f(m-1, 3, matrix, dp)

### SOLUTION 2: BOTTOM UP APPROACH (time: O(n*4*3)
class Solution:
    def ninjaTraining(self, points: List[List[int]]) -> int:
        num_days = len(points)
        if num_days == 0:
            return 0
            
        num_tasks = 3
        # We need 4 states: 3 specific tasks + 1 state representing "no previous task"
        num_states = 4 
        
        # Initialize a 2D DP table with zeros
        dp = [[0 for _ in range(num_states)] for _ in range(num_days)]
        
        # --- Base Case: Day 0 ---
        # If we are forced to pick a different task tomorrow, these are our starting points today
        dp[0][0] = points[0][0]
        dp[0][1] = points[0][1]
        dp[0][2] = points[0][2]
        
        # State 3: When there are no restrictions (e.g., the very end of the evaluation)
        dp[0][3] = max(points[0][0], points[0][1], points[0][2])
        
        # --- DP Transitions ---
        for day in range(1, num_days):
            for last_task in range(num_states):
                
                # Check every possible task we could perform today
                for current_task in range(num_tasks):
                    
                    # Rule check: Cannot perform the same task as yesterday
                    if current_task != last_task:
                        
                        # Points = Today's reward + Max points earned up to yesterday for this sequence
                        earned_points = points[day][current_task] + dp[day - 1][current_task]
                        
                        # Keep the maximum points found for this state
                        dp[day][last_task] = max(dp[day][last_task], earned_points)
                        
        # Return the max points on the final day, evaluated from the "no restriction" state (3)
        return dp[num_days - 1][3]

### SOLUTION 3: Space Optimized space: (O(4)) Time: O(n*4*3)
class Solution:
    def ninjaTraining(self, points: List[List[int]]) -> int:
        num_days = len(points)
        
        # Edge case: If there are no days, return 0
        if num_days == 0:
            return 0
            
        num_tasks = 3
        num_states = 4
        
        # 'dp' represents the maximum points calculated for the previous day
        dp = [0] * num_states
        
        # --- Base Case: Day 0 ---
        dp[0] = max(points[0][1], points[0][2])
        dp[1] = max(points[0][0], points[0][2])
        dp[2] = max(points[0][0], points[0][1])
        dp[3] = max(points[0][0], points[0][1], points[0][2])

        # --- DP Transitions ---
        for day in range(1, num_days):
            # 'temp' stores the calculations for the current day
            temp = [0] * num_states
            
            for last_task in range(num_states):
                for current_task in range(num_tasks):
                    
                    if last_task != current_task:
                        earned_points = points[day][current_task] + dp[current_task]
                        temp[last_task] = max(temp[last_task], earned_points)
            
            # The current day becomes the "previous day" for the next loop iteration
            dp = temp
            
        # Return the max points on the final day from the "no restriction" state
        return dp[3]

```

### Problem 2: Unique Paths (GRID Problem)

[https://leetcode.com/problems/unique-paths/?utm=codolio](https://leetcode.com/problems/unique-paths/?utm=codolio) — LC 62: Unique Paths

**Recursion tree** (example: `f(i,j)` = paths to cell `(i,j)`, target `f(2,2)` in a 3×3 grid):

```
                         f(2,2)
                        /      \
               f(1,2) up        f(2,1) left
               /    \               /    \
          f(0,2)  f(1,1) ←──── f(1,1)  f(2,0)
                     ↑ same cell reached from two paths → 2D DP
```

Robot at top-left `(0,0)` must reach bottom-right `(m-1, n-1)`. Only moves **right** or **down**. Count total unique paths.

Recurrence: `dp[i][j] = dp[i-1][j] + dp[i][j-1]` with `dp[0][0] = 1`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(m*n) | Space: O(m*n) — memo stores each cell once
class Solution:
    def f(self, i, j, dp):
        if i == 0 and j == 0: return 1  # one way to stay at origin
        if i < 0 or j < 0: return 0     # out of bounds
        if dp[i][j] != -1:
            return dp[i][j]             # return cached result

        up = self.f(i - 1, j, dp)       # came from above
        left = self.f(i, j - 1, dp)     # came from left
        dp[i][j] = up + left
        return dp[i][j]

    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[-1 for _ in range(n)] for _ in range(m)]
        return self.f(m - 1, n - 1, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — fill grid bottom-up
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[0 for _ in range(n)] for _ in range(m)]

        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    dp[i][j] = 1
                else:
                    up = dp[i - 1][j] if i > 0 else 0
                    left = dp[i][j - 1] if j > 0 else 0
                    dp[i][j] = up + left

        return dp[m - 1][n - 1]

## SOLUTION 3: Space optimized in DP (1D Tabulation)
# Time: O(m*n) | Space: O(n) — only keep previous row
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [0] * n  # previous row

        for i in range(m):
            temp = [0] * n  # current row being built
            for j in range(n):
                if i == 0 and j == 0:
                    temp[j] = 1
                else:
                    up = dp[j] if i > 0 else 0       # cell above (prev row)
                    left = temp[j - 1] if j > 0 else 0  # cell to the left (same row)
                    temp[j] = up + left
            dp = temp  # current row becomes previous row

        return dp[n - 1]
```

### Problem 3: Minimum Sum Path

[https://leetcode.com/problems/minimum-path-sum/description/?utm=codolio](https://leetcode.com/problems/minimum-path-sum/description/?utm=codolio) — LC 64: Minimum Path Sum

**Grid diagram** — only move **right (→)** or **down (↓)** from `(0,0)` to `(m-1, n-1)`:

```
  Start
    ↓
  [1] → [3] → [1]
    ↓     ↓     ↓
  [1] → [5] → [1]
    ↓     ↓     ↓
  [4] → [2] → [1]  ← End (min-sum path: 1→3→1→1→1 = 7)
```

**DP fill** — `dp[i][j]` = min cost to reach `(i,j)`; each cell adds its value to the cheaper incoming path:

```
              j=0    j=1    j=2
         ┌─────────────────────────┐
  i=0    │   1  →   4  →   5       │  row 0: only moves right
         ├─────────────────────────┤
  i=1    │   2  →   7  →   6       │  dp[i][j] = grid[i][j] + min(top, left)
         ├─────────────────────────┤
  i=2    │   6  →   8  →   7  ✓    │  answer = dp[2][2]
         └─────────────────────────┘

  e.g. dp[1][1] = 5 + min(dp[0][1]=4, dp[1][0]=2) = 5 + 2 = 7
```

**Recursion tree** (example: `f(i,j)` = min sum to `(i,j)`, target `f(2,2)`):

```
                         f(2,2)
                        /      \
               f(1,2) top        f(2,1) left
               /    \               /    \
          f(0,2)  f(1,1) ←──── f(1,1)  f(2,0)
                     ↑ same subproblem reused → 2D DP
```

Recurrence: `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])` with `dp[0][0] = grid[0][0]`.

```python
## SOLUTION 1: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — fill grid row by row
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m = len(grid)
        n = len(grid[0])
        dp = [[0 for _ in range(n)] for _ in range(m)]

        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    dp[i][j] = grid[0][0]  # start cell
                    continue
                top = grid[i][j] + dp[i - 1][j] if i > 0 else float("inf")
                left = grid[i][j] + dp[i][j - 1] if j > 0 else float("inf")
                dp[i][j] = min(top, left)

        return dp[m - 1][n - 1]

## SOLUTION 2: Space optimized in DP (1D Tabulation)
# Time: O(m*n) | Space: O(n) — one row; dp[j] updated in place per row
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m = len(grid)
        n = len(grid[0])

        dp = [float("inf")] * n
        dp[0] = 0
        for i in range(m):
            for j in range(n):
                if j == 0:
                    dp[j] += grid[i][j]           # only path is from above
                else:
                    dp[j] = grid[i][j] + min(dp[j], dp[j - 1])  # min(top, left)

        return dp[-1]
```

### Problem 4: Minimum Path Sum in Triangular Grid

[https://leetcode.com/problems/triangle/description/?utm=codolio](https://leetcode.com/problems/triangle/description/?utm=codolio) — LC 120: Triangle

**Triangle diagram** — from `(i, j)` you may only move to `(i+1, j)` or `(i+1, j+1)`:

```
              [2]                 row 0
             /   \
          [3]     [4]             row 1
         /   \   /   \
      [6]     [5]     [7]         row 2
     /   \   /   \   /   \
   [4]     [1]     [8]     [3]     row 3 (bottom)

  min path: 2 → 3 → 5 → 1  =  11
```

**DP fill (bottom-up)** — start at the bottom row, work upward; each cell picks the cheaper child:

```
  row 3 (base):     4      1      8      3
                      \    / \    / \    /
  row 2:             7      6     10
                      \    / \    /
  row 1:             9     10
                        \  /
  row 0:              11  ✓   answer = dp[0][0]

  e.g. dp[1][0] = 3 + min(dp[2][0]=7, dp[2][1]=6) = 3 + 6 = 9
```

**Recursion tree** (example: `f(i,j)` = min sum from `(i,j)` to bottom, target `f(0,0)`):

```
                         f(0,0)
                        /      \
               f(1,0)           f(1,1)
              /    \           /    \
         f(2,0)  f(2,1)   f(2,1)  f(2,2)
              ↑ f(2,1) shared by two parents → memo / tabulation
```

Recurrence: `dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])`. Base case: bottom row `dp[m-1][j] = triangle[m-1][j]`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n²) | Space: O(n²) — n = number of rows; memo stores each (i,j) once
class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        memo = {}
        m = len(triangle)

        def bt(i, j):
            if i == m - 1:
                return triangle[i][j]  # bottom row
            if (i, j) in memo:
                return memo[(i, j)]

            down = bt(i + 1, j)         # move to (i+1, j)
            diag = bt(i + 1, j + 1)     # move to (i+1, j+1)
            memo[(i, j)] = triangle[i][j] + min(down, diag)
            return memo[(i, j)]

        return bt(0, 0)

## SOLUTION 2: Time optimized using DP (Bottom-Up Tabulation)

        for i in range(m - 2, -1, -1):
            for j in range(i, -1, -1):
                dp[i][j] = triangle[i][j] + min(dp[i + 1][j], dp[i + 1][j + 1])

        return dp[0][0]

        for i in range(m - 2, -1, -1):
            for j in range(i + 1):
                dp[j] = triangle[i][j] + min(dp[j], dp[j + 1])

        return dp[0]
```

### Problem 5: Minimum Falling Path Sum

[https://leetcode.com/problems/minimum-falling-path-sum/description/?utm=codolio](https://leetcode.com/problems/minimum-falling-path-sum/description/?utm=codolio) — LC 931: Minimum Falling Path Sum

**Grid diagram** — start at **any cell in row 0**; from `(i, j)` fall to `(i+1, j-1)`, `(i+1, j)`, or `(i+1, j+1)`:

```
  row 0:   [2]   [1]   [3]     ← start anywhere in top row
            ↘ ↓ ↘  ↘ ↓ ↘  ↘ ↓ ↘
  row 1:   [6]   [5]   [7]
            ↘ ↓ ↘  ↘ ↓ ↘  ↘ ↓ ↘
  row 2:   [4]   [8]   [1]     ← end anywhere in bottom row

  min falling path: 1 → 5 → 1  =  7
```

**DP fill (bottom-up)** — each cell adds its value to the min of up to 3 cells in the row below:

```
              j=0    j=1    j=2
         ┌─────────────────────────┐
  i=0    │   8      7 ✓     9     │  answer = min(row 0) = 7
         ├─────────────────────────┤
  i=1    │  10      6      8      │  dp[i][j] = matrix[i][j] + min(left, center, right)
         ├─────────────────────────┤
  i=2    │   4      8      1      │  base case: bottom row
         └─────────────────────────┘

  e.g. dp[0][1] = 1 + min(dp[1][0]=10, dp[1][1]=6, dp[1][2]=8) = 1 + 6 = 7
```

**Recursion tree** (example: `f(i,j)` = min sum from `(i,j)` to bottom, best path starts at `(0,1)`):

```
                         f(0,1)
                        /  |  \
               f(1,0)  f(1,1)  f(1,2)
               /|\     /|\     /|\
            f(2,*)  f(2,*)  f(2,*)   → base: matrix[2][j]
               ↑ f(1,1) is shared by f(0,0), f(0,1), f(0,2) → memo
```

Recurrence: `dp[i][j] = matrix[i][j] + min(dp[i+1][j-1], dp[i+1][j], dp[i+1][j+1])` (out-of-bounds neighbors = `∞`). Base: bottom row. Answer: `min(dp[0][j])` over all columns.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n²) | Space: O(n²) — n×n matrix; memo stores each (i,j) once
class Solution:
    def minFallingPathSum(self, matrix: List[List[int]]) -> int:
        m = len(matrix)
        n = len(matrix[0])
        memo = {}

        def bt(i, j):
            if (i, j) in memo:
                return memo[(i, j)]
            if j < 0 or j >= n:
                return float("inf")  # invalid column
            if i == m:
                return 0             # past last row

            left = matrix[i][j] + bt(i + 1, j - 1)
            center = matrix[i][j] + bt(i + 1, j)
            right = matrix[i][j] + bt(i + 1, j + 1)
            memo[(i, j)] = min(left, center, right)
            return memo[(i, j)]

        return min(bt(0, j) for j in range(n))  # best start column in row 0

## SOLUTION 2: Time optimized using DP (Bottom-Up Tabulation)
# Time: O(n²) | Space: O(n²) — fill table from bottom row to top
class Solution:
    def minFallingPathSum(self, matrix: List[List[int]]) -> int:
        m = len(matrix)
        n = len(matrix[0])
        dp = [[0 for _ in range(n)] for _ in range(m)]

        for j in range(n):
            dp[m - 1][j] = matrix[m - 1][j]  # base case: bottom row

        for i in range(m - 2, -1, -1):
            for j in range(n):
                left = dp[i + 1][j - 1] if j > 0 else float("inf")
                center = dp[i + 1][j]
                right = dp[i + 1][j + 1] if j < n - 1 else float("inf")
                dp[i][j] = matrix[i][j] + min(left, center, right)

        return min(dp[0])  # best start column in row 0

## SOLUTION 3: Space optimized in DP
# Time: O(n²) | Space: O(n) — one row; dp[j] = min falling sum from row i, col j
class Solution:
    def minFallingPathSum(self, matrix: List[List[int]]) -> int:
        m = len(matrix)
        n = len(matrix[0])
        dp = matrix[m - 1][:]  # start with bottom row values

        for i in range(m - 2, -1, -1):
            temp = [0] * n
            for j in range(n):
                left = dp[j - 1] if j > 0 else float("inf")
                center = dp[j]
                right = dp[j + 1] if j < n - 1 else float("inf")
                temp[j] = matrix[i][j] + min(left, center, right)
            dp = temp

        return min(dp)
```

### Problem 6: Ninja and His Friends (3D DP)

[https://takeuforward.org/plus/dsa/problems/ninja-and-his-friends?utm=codolio](https://takeuforward.org/plus/dsa/problems/ninja-and-his-friends?utm=codolio)

**Grid diagram** — two ninjas start at `(0,0)` and `(0,c-1)`; each row they move down and may shift column by `-1, 0, or +1`. Same cell → count chocolate **once**:

```
  row 0:  N1→ [1]  [2]  [3] ←N2        start: cols 0 and c-1
           ↘↓↘  ↘↓↘  ↘↓↘              each ninja picks one of 3 moves
  row 1:      [4]  [5]  [6]
           ↘↓↘  ↘↓↘  ↘↓↘
  row 2:      [7]  [8]  [9]            base case: last row

  if j1 == j2 → gain = grid[i][j1]
  else        → gain = grid[i][j1] + grid[i][j2]
```

**3D DP state** — `dp[i][j1][j2]` = max chocolates from row `i` onward when ninjas are at columns `j1` and `j2`:

```
              j2 →
         ┌───────────────────┐
  i=2    │  base: fill all   │  dp[2][j1][j2] from grid values
         ├───────────────────┤
  i=1    │  for each (j1,j2) │  try 9 move pairs → pick max
         │  pair, add gain   │
         ├───────────────────┤
  i=0    │  dp[0][0][c-1] ✓  │  answer (start positions)
         └───────────────────┘
```

**Recursion tree** (example: `f(i,j1,j2)` = max from row `i`, target `f(0,0,2)` on a 3×3 grid):

```
                         f(0,0,2)
                    /  /  |  \  \  ... (9 move pairs)
              f(1,0,1) f(1,0,2) f(1,1,1) f(1,1,2) ...
                    ↑ same (i,j1,j2) reached via different paths → 3D memo
```

Recurrence: `dp[i][j1][j2] = gain(i,j1,j2) + max dp[i+1][j1+dj1][j2+dj2]` over `dj1, dj2 ∈ {-1,0,1}` (invalid cols skipped). Answer: `dp[0][0][c-1]`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(r*c²*9) | Space: O(r*c²) — state = (row, col1, col2)
class Solution:
    def maxChocolates(self, g):
        r, c = len(g), len(g[0])
        dp = [[[-1 for _ in range(c)] for _ in range(c)] for _ in range(r)]  # dp[i][j1][j2]

        def bt(i, j1, j2):
            if j1 < 0 or j2 < 0 or j1 >= c or j2 >= c:
                return -float("inf")  # invalid column → prune this path
            if i == r - 1:
                return g[i][j1] if j1 == j2 else g[i][j1] + g[i][j2]  # base: last row
            if dp[i][j1][j2] != -1:
                return dp[i][j1][j2]  # return cached result

            maxi = -float("inf")
            # try all 9 combined moves: each ninja shifts col by -1, 0, or +1
            for dj1 in range(-1, 2):
                for dj2 in range(-1, 2):
                    gain = g[i][j1] if j1 == j2 else g[i][j1] + g[i][j2]  # same cell → count once
                    maxi = max(maxi, gain + bt(i + 1, j1 + dj1, j2 + dj2))

            dp[i][j1][j2] = maxi
            return maxi

        return bt(0, 0, c - 1)  # N1 at col 0, N2 at col c-1

## SOLUTION 2: Time optimized using DP (Bottom-Up Tabulation)

        for j1 in range(c):

                dp[r - 1][j1][j2] = g[r - 1][j1] if j1 == j2 else g[r - 1][j1] + g[r - 1][j2]

        for i in range(r - 2, -1, -1):
            for j1 in range(c):
                for j2 in range(c):
                    maxi = -float("inf")
                    for dj1 in range(-1, 2):
                        for dj2 in range(-1, 2):
                            nj1, nj2 = j1 + dj1, j2 + dj2  # next-row columns
                            if 0 <= nj1 < c and 0 <= nj2 < c:

                                maxi = max(maxi, gain + dp[i + 1][nj1][nj2])
                    dp[i][j1][j2] = maxi  # best from row i with ninjas at j1, j2

        return dp[0][0][c - 1]  # start positions: row 0, cols 0 and c-1
```

## DP on Subsets / Sequences

This family covers problems like **Subset Sum**, **Partition Equal Subset Sum**, **0/1 Knapsack**, **Count Subsets with Target**, **Coin Change**, and **Rod Cutting**. They all share the same "pick / not-pick" thinking.

**The thinking template (Shortcut to the recurrence)**

1. **Express everything in terms of index + state**
  - State is usually `f(ind, target)` where `ind` = "items 0..ind are available" and `target` = the remaining goal (sum / capacity / amount).
2. **Explore all choices on that index** — the two core options:
  - **Not pick** `arr[ind]` → move to `f(ind - 1, target)`.
  - **Pick** `arr[ind]` → allowed only if it "fits" (`arr[ind] <= target`) → `f(ind - 1, target - arr[ind])` (add value/count as needed).
3. **Combine + return** based on what the problem asks:
  - Exists / feasibility → `pick OR not_pick`
  - Count ways → `pick + not_pick`
  - Min / Max value → `min/max(pick, not_pick)`

**Base cases:**

- **Reached first index** `ind == 0`: answer depends only on `arr[0]` vs `target`.
  - *Feasibility:* `return arr[0] == target `
  - *Count:* handle `target == 0` and `arr[0] == target` carefully (watch the `arr[0] == 0` edge case → 2 ways).
- **Target met** `target == 0`: often `return True` / `return 1` early.

### Pseudocode (generic pick / not-pick)

```text
f(ind, target):
    # --- base cases ---
    if target == 0:            return BASE_TARGET_MET      # True / 1
    if ind == 0:               return check(arr[0], target)

    # --- memo lookup ---
    if dp[ind][target] != -1:  return dp[ind][target]

    # --- explore choices ---
    not_pick = f(ind - 1, target)

    pick = IDENTITY             # 0 for count/max, +inf for min, False for feasibility
    if arr[ind] <= target:
        pick = f(ind - 1, target - arr[ind])   # (+ value / +1 depending on problem)

    # --- combine ---
    dp[ind][target] = COMBINE(pick, not_pick)   # OR / + / min / max
    return dp[ind][target]
```

### **Recursion → Tabulation → Space optimization**

- **Memoization:** table size `dp[n][target + 1]`, initialised to `-1`.
- **Tabulation:** loop `ind` from `0 → n-1`, `target` from `0 → maxTarget`; the recursion's base cases become the **first row** (`ind == 0`) initialisation.
- **Space optimization:** each row depends only on `ind - 1`, so keep two 1D arrays `prev` and `curr`.

### Space optimization trick: traverse `target` forward or backward?

Once you collapse `dp[ind][target]` into a single 1D array, the direction of the inner `target` loop depends on **whether the item can be reused (unbounded) or not (0/1)**:

```
0/1 (item used at most once)         Unbounded (item reusable)
──────────────────────────────       ──────────────────────────────
for w in range(W, -1, -1):           for target in range(0, amount+1):
    take = val[i] + dp[w-wt[i]]          take = 1 + dp[target-coin[i]]
    ↑ dp[w-wt[i]] is still the           ↑ dp[target-coin[i]] is the value
    OLD row (ind-1) — not yet            ALREADY updated in THIS row (ind) —
    overwritten this iteration           exactly what we want (reuse!)
```

- **0/1 items (Knapsack, Subset Sum, Partition, Count Subsets)** → traverse `target`/`W` **backward** (`range(W, -1, -1)`). A single array `dp` is being overwritten in place; going backward guarantees `dp[w - wt[i]]` (a smaller index) still holds **last row's** value when you read it, so item `i` isn't accidentally picked twice.
- **Unbounded items (Coin Change, Rod Cutting)** → traverse `target`/`amount` **forward** (`range(0, amount+1)`). Going forward means `dp[target - coin[i]]` has **already been updated this row**, i.e. it reflects a solution that may already include coin `i` — which is exactly what "unlimited supply" requires.

> **One-line rule:** *backward = "use it once", forward = "use it as many times as helps".*

Note this trick only applies to the **1D space-optimized** version — the 2D tabulation (`prev`/`curr` or full `dp[ind][target]`) doesn't need it because `dp[ind-1][...]` and `dp[ind][...]` are already separate rows regardless of loop direction.

### Quick mapping of common problems

| Problem                 | State            | Choice value              | Combine |
| ----------------------- | ---------------- | ------------------------- | ------- |
| Subset Sum (exists)     | `f(ind, target)` | —                         | `OR`    |
| Count Subsets = target  | `f(ind, target)` | `+1` at match             | `+`     |
| 0/1 Knapsack            | `f(ind, W)`      | `+ value[ind]`            | `max`   |
| Min Coins (Coin Change) | `f(ind, amount)` | `+1` per coin, unbounded  | `min`   |
| Rod Cutting             | `f(ind, len)`    | `+ price[ind]`, unbounded | `max`   |

> **Unbounded vs 0/1:** if an item can be reused (coins, rod pieces), the *pick* branch stays on the **same index** `f(ind, target - arr[ind])` instead of moving to `ind - 1`.

### Problem 1: Check if there exists a subsequence with sum K

[https://takeuforward.org/plus/dsa/problems/check-if-there-exists-a-subsequence-with-sum-k?utm=codolio](https://takeuforward.org/plus/dsa/problems/check-if-there-exists-a-subsequence-with-sum-k?utm=codolio)

Given `nums` and target `k`, return `True` if **any** subsequence sums to exactly `k`. Classic *pick / not-pick* feasibility problem.

**Recursion tree** (example: `nums = [1, 2, 3]`, `k = 3`; state `f(ind, target)`):

```
                       f(2, 3)
                 not-pick /   \ pick nums[2]=3
                    f(1, 3)     f(1, 0) → target 0 → True ✓
              np  /      \  pick 2
          f(0, 3)       f(0, 1)
          3==3? →False   1==1? → True ✓
              ↑ (ind, target) pairs repeat across branches → 2D memo
```

Recurrence: `f(ind, t) = f(ind-1, t)  OR  f(ind-1, t - nums[ind])` (pick only if `nums[ind] <= t`).  
Base cases: `t == 0 → True`, `ind == 0 → nums[0] == t`.

**DP table** — `dp[i][t]` = can a subsequence of `nums[0..i]` reach sum `t`? (`T` = True):

```
        t=0   1    2    3
      ┌─────────────────────┐
  i=0 │  T    T    .    .   │  nums[0]=1 → dp[0][0]=T, dp[0][1]=T
  i=1 │  T    T    T    T   │  +2 → sums {0,1,2,3} reachable
  i=2 │  T    T    T    T ✓ │  +3 → answer = dp[2][3] = True
      └─────────────────────┘
   col t=0 is always True (empty subsequence)
```

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n*k) | Space: O(n*k) + O(n) stack — state = (index, target)
class Solution:
    def f(self, ind, target, nums, dp):
        if target == 0:
            return True                 # empty pick reaches target
        if ind == 0:
            return nums[0] == target     # only first element left

        if dp[ind][target] != -1:
            return dp[ind][target]       # return cached result

        notTake = self.f(ind - 1, target, nums, dp)   # skip nums[ind]
        take = False
        if nums[ind] <= target:                        # pick only if it fits
            take = self.f(ind - 1, target - nums[ind], nums, dp)

        dp[ind][target] = take or notTake
        return dp[ind][target]

    def checkSubsequenceSum(self, nums, k):
        n = len(nums)
        dp = [[-1 for _ in range(k + 1)] for _ in range(n)]
        return self.f(n - 1, k, nums, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(n*k) | Space: O(n*k) — recursion base cases become first row + col 0
class Solution:
    def checkSubsequenceSum(self, nums, k):
        n = len(nums)
        dp = [[False for _ in range(k + 1)] for _ in range(n)]

        for i in range(n):
            dp[i][0] = True             # target 0 always reachable (pick nothing)

        if nums[0] <= k:
            dp[0][nums[0]] = True        # base: first element alone

        for i in range(1, n):
            for j in range(1, k + 1):
                notTake = dp[i - 1][j]
                take = False
                if nums[i] <= j:
                    take = dp[i - 1][j - nums[i]]
                dp[i][j] = take or notTake

        return dp[n - 1][k]

## SOLUTION 3: Space optimized in DP
# Time: O(n*k) | Space: O(k) — each row needs only the previous row
class Solution:
    def checkSubsequenceSum(self, nums, k):
        n = len(nums)
        prev = [False for _ in range(k + 1)]
        prev[0] = True                   # target 0 reachable
        if nums[0] <= k:
            prev[nums[0]] = True          # base: first element alone

        for i in range(1, n):
            curr = [False for _ in range(k + 1)]
            curr[0] = True
            for j in range(1, k + 1):
                notTake = prev[j]
                take = False
                if nums[i] <= j:
                    take = prev[j - nums[i]]
                curr[j] = take or notTake
            prev = curr                   # slide window: curr becomes prev

        return prev[k]
```

### Problem 2: Partition Array into Two Arrays to Minimize Sum Difference

[https://leetcode.com/problems/partition-array-into-two-arrays-to-minimize-sum-difference/description/?utm=codolio](https://leetcode.com/problems/partition-array-into-two-arrays-to-minimize-sum-difference/description/?utm=codolio)

Split `nums` into two subsets `S1` and `S2` so that `|sum(S1) - sum(S2)|` is **minimized**. Direct extension of "Subset Sum" — instead of checking one target, check **every achievable sum** and pick the one closest to `totalSum / 2`.

**Key idea diagram** — let `total = sum(nums)`. If a subset sums to `s`, the other subset sums to `total - s`, so the difference is `|total - 2s|`. This is smallest when `s` is as close as possible to `total / 2`:

```
0 ────────────────────────────── total/2 ────────────────────────── total
                                     ↑
                     scan achievable sums s = 0 .. total/2
                     pick the s closest to total/2
                     diff = |(total - s) - s| = |total - 2s|
```

**Reusing the Subset-Sum table** (Problem 1) — build `dp[i][s]` = "can subset of `nums[0..i]` sum to `s`?" for **every** `s` in `0..total`. The last row `dp[n-1]` tells us which sums `s <= total/2` are reachable:

```
        s=0   1    2   ...  total/2
      ┌──────────────────────────────┐
  ... │  ...  ...  ...  ...   ...    │
 last │  T    F    T   ...    T ✓    │  ← scan left half, find reachable s
      └──────────────────────────────┘
                              closest reachable s to total/2 → min diff
```

Recurrence (same as Problem 1, target replaced by `total`): `dp[i][s] = dp[i-1][s] OR dp[i-1][s - nums[i]]`, base `dp[i][0] = True`.

```python
## SOLUTION 1: Subset-Sum DP, Space Optimized
# Time: O(n * total) | Space: O(total) — build reachable sums, then scan for closest half
class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums)
        k = sum(nums)  # total sum; target range for subset sum is 0..k

        prev = [False for _ in range(k + 1)]
        prev[0] = True                    # sum 0 always reachable (empty subset)
        if nums[0] <= k:
            prev[nums[0]] = True           # base: first element alone

        for i in range(1, n):
            curr = [False for _ in range(k + 1)]
            curr[0] = True
            for j in range(1, k + 1):
                notTake = prev[j]
                take = False
                if nums[i] <= j:
                    take = prev[j - nums[i]]
                curr[j] = take or notTake
            prev = curr                    # slide window: curr becomes prev

        # prev[s] == True  ⇒  some subset sums to s, other subset sums to (k - s)
        half = k // 2
        mini = float("inf")
        for s in range(half + 1):          # only need to check s up to k/2
            if prev[s]:
                mini = min(mini, abs((k - s) - s))  # |sum(S2) - sum(S1)|

        return mini
```

### Problem 3: Count All Subsequences with Sum K

[https://takeuforward.org/plus/dsa/problems/count-all-subsequences-with-sum-k?utm=codolio](https://takeuforward.org/plus/dsa/problems/count-all-subsequences-with-sum-k?utm=codolio)

Same setup as Problem 1 (subsequence summing to `k`), but instead of asking **does one exist?**, we ask **how many exist?** Only the *combine* step changes — everything else in the pattern stays identical.

**Recursion tree** (example: `nums = [1, 2, 3]`, `k = 3`; state `f(ind, target)` = count of subsequences from `nums[0..ind]` summing to `target`):

```
                            f(2, 3)
                pick 3    /        \    not-pick
                         /          \
                   f(1, 0)          f(1, 3)
                  (target hit)     pick 2 /  \ not-pick
                       |               /      \
                    count=1       f(0, 1)   f(0, 3)
                                  1==1?T    3==3?F
                                  count=1   count=0
                                     ↑
                    total count = 1 (from left) + 1 + 0 = 2
                    subsequences: {3}, {1,2}
```

**How it connects to the pattern:**

- **State** is unchanged: `f(ind, target)`.
- **Explore choices** is unchanged: *pick* `nums[ind]` (if it fits) → `f(ind-1, target-nums[ind])`, *not-pick* → `f(ind-1, target)`.
- **Combine** changes from `OR` (Problem 1: "does a way exist?") to `+` (Problem 3: "how many ways?") — `f(ind, target) = pick + notPick`.
- **Base cases** change from booleans to counts:
  - `target == 0` → `1` way (the empty subsequence), instead of `True`.
  - `ind == 0` → `1` if `nums[0] == target` else `0`, instead of a boolean equality check.
  - Special care needed if `nums[0] == 0`: both "pick it" and "don't pick it" reach `target == 0`, so that base case can contribute `2` ways, a classic edge case in this pattern.

This "swap OR for +, swap True/False for 1/0" substitution is exactly the **Count Subsets = target** row from the mapping table above, and the same substitution turns Problem 1's code (recursion → tabulation → space-optimized) into a working solution here with almost no structural change.

### Problem 4: 0/1 Knapsack

[https://takeuforward.org/plus/dsa/problems/0-1-knapsack?utm=codolio](https://takeuforward.org/plus/dsa/problems/0-1-knapsack?utm=codolio)

Given `n` items with `weight[i]` and `value[i]`, and a knapsack of capacity `W`, pick a subset of items (each item used **at most once**) to **maximize total value** without exceeding `W`. The template's `target` becomes the remaining **capacity**, and `OR`/`+` (from Problems 1 & 3) becomes `max`, with value added instead of just a boolean/count.

**Recursion tree** (example: `wt=[1,2,3]`, `val=[10,15,40]`, `W=4`; state `f(ind, W)` = max value using `wt[0..ind]` within capacity `W`):

```
                                f(2, 4)
                pick wt[2]=3 /          \ not-pick
                            /              \
                 40 + f(1, 1)              f(1, 4)
                 (wt[1]=2 > 1,      pick wt[1]=2 /  \ not-pick
                  can't pick)         15 + f(0,2)    f(0,4)
                       |               wt[0]=1<=2      wt[0]=1<=4
                  f(0,1)=10           f(0,1)=10       f(0,4)=10
                  → 40+10=50          → 15+10=25      → 10

                        best = max(50, 25, 10) = 50
```

**How it connects to the pattern:**

- **State**: `f(ind, W)` — identical shape to `f(ind, target)`, just renaming `target → W` (remaining capacity).
- **Explore choices**: *not-pick* → `f(ind-1, W)` (unchanged). *pick* → allowed only if `wt[ind] <= W`, then `value[ind] + f(ind-1, W - wt[ind])` — same "fits the target" guard as Problems 1 & 3, plus we now **carry a value** instead of just moving forward.
- **Combine**: `max(pick, notPick)` instead of `OR` (Problem 1) or `+` (Problem 3) — this is the **Optimization** flavor of the same template (want *best* value, not just *existence* or *count*).
- **Base case** `ind == 0`: take `val[0]` if `wt[0] <= W`, else `0` — same shape as `nums[0] == target` in Problem 1, but returns a value instead of a boolean.

This is exactly the **0/1 Knapsack** row from the earlier mapping table: state `f(ind, W)`, choice value `+ value[ind]`, combine `max`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n*W) | Space: O(n*W) + O(n) stack — state = (index, capacity)
class Solution:
    def f(self, ind, W, wt, val, dp):
        if ind == 0:
            return val[0] if wt[0] <= W else 0  # only first item available

        if dp[ind][W] != -1:
            return dp[ind][W]                    # return cached result

        notTake = self.f(ind - 1, W, wt, val, dp)  # skip item ind
        take = float("-inf")
        if wt[ind] <= W:                            # pick only if it fits
            take = val[ind] + self.f(ind - 1, W - wt[ind], wt, val, dp)

        dp[ind][W] = max(take, notTake)
        return dp[ind][W]

    def knapsack01(self, wt, val, n, W):
        dp = [[-1 for _ in range(W + 1)] for _ in range(n)]
        return self.f(n - 1, W, wt, val, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(n*W) | Space: O(n*W) — recursion base case becomes the first row
class Solution:
    def knapsack01(self, wt, val, n, W):
        dp = [[0 for _ in range(W + 1)] for _ in range(n)]

        for w in range(wt[0], W + 1):
            dp[0][w] = val[0]                        # base: only item 0 available

        for ind in range(1, n):
            for w in range(W + 1):
                notTake = dp[ind - 1][w]
                take = float("-inf")
                if wt[ind] <= w:
                    take = val[ind] + dp[ind - 1][w - wt[ind]]
                dp[ind][w] = max(take, notTake)

        return dp[n - 1][W]

## SOLUTION 3: Space optimized in DP
# Time: O(n*W) | Space: O(W) — iterate w right-to-left so prev[w-wt] isn't overwritten yet
class Solution:
    def knapsack01(self, wt, val, n, W):
        prev = [0 for _ in range(W + 1)]

        for w in range(wt[0], W + 1):
            prev[w] = val[0]                         # base: only item 0 available

        for ind in range(1, n):
            for w in range(W, -1, -1):                # right-to-left: 1D 0/1 knapsack trick
                notTake = prev[w]
                take = float("-inf")
                if wt[ind] <= w:
                    take = val[ind] + prev[w - wt[ind]]
                prev[w] = max(take, notTake)

        return prev[W]
```

### Problem 5: Coin Change (Minimum Coins)

[https://leetcode.com/problems/coin-change/description/?utm=codolio](https://leetcode.com/problems/coin-change/description/?utm=codolio)

Given `coins` (unlimited supply of each) and an `amount`, find the **minimum number of coins** needed to make `amount`. `target` becomes the remaining **amount**, `min` is the combine (want fewest coins), and this is the first **unbounded** problem in the series, a coin can be reused, so the *pick* branch does **not** move to `ind - 1`.

**Recursion tree** (example: `coins = [1, 2]`, `amount = 3`; state `f(ind, target)` = min coins from `coins[0..ind]` to make `target`):

```
                              f(1, 3)
             pick coin[1]=2 /          \ not-pick
                  same ind ↓              ↓ ind-1
             1 + f(1, 1)                f(0, 3)
                    |                   3 % 1 == 0 → 3 // 1 = 3
             pick 2? 2<=1 false
             not-pick → f(0, 1)
             1 % 1 == 0 → 1
                    ↓
             f(1,1) = min(inf, 1) = 1

        f(1, 3) = min(1 + f(1,1), f(0,3)) = min(1 + 1, 3) = 2
        (uses coins {1, 2})
```

**How it connects to the pattern:**

- **State**: `f(ind, target)` — same shape as Problems 1–4, `target` = remaining amount.
- **Explore choices**: *not-pick* → `f(ind-1, target)` (unchanged — move to the previous coin). *pick* → allowed only if `coin[ind] <= target`, but since coins are **reusable**, it stays on the **same** `ind`: `1 + f(ind, target - coin[ind])`. This is the "unbounded" tweak from the earlier note.
- **Combine**: `min(pick, notPick)` — same "optimize" flavor as Knapsack, but minimizing count instead of maximizing value.
- **Base case** `ind == 0`: only the first coin is available, reusable any number of times → `target // coin[0]` if `target % coin[0] == 0`, else `∞` (can't be made).
- **Final answer**: convert `∞` (unreachable) to `-1`, as required by the problem.

This is exactly the **Min Coins (Coin Change)** row from the mapping table: state `f(ind, amount)`, choice `+1` per coin (unbounded), combine `min`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(n*amount) | Space: O(n*amount) + O(amount) stack — state = (index, target)
class Solution:
    def f(self, ind, target, coin, dp):
        if ind == 0:
            # only coin[0] available, reusable → must divide evenly
            return target // coin[0] if target % coin[0] == 0 else float("inf")

        if dp[ind][target] != -1:
            return dp[ind][target]              # return cached result

        notTake = self.f(ind - 1, target, coin, dp)   # move to previous coin
        take = float("inf")
        if coin[ind] <= target:
            take = 1 + self.f(ind, target - coin[ind], coin, dp)  # same ind: coin is reusable

        dp[ind][target] = min(take, notTake)
        return dp[ind][target]

    def coinChange(self, coins: List[int], amount: int) -> int:
        n = len(coins)
        dp = [[-1 for _ in range(amount + 1)] for _ in range(n)]
        ans = self.f(n - 1, amount, coins, dp)
        return ans if ans != float("inf") else -1

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(n*amount) | Space: O(n*amount) — recursion base case becomes the first row
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        n = len(coins)
        dp = [[0 for _ in range(amount + 1)] for _ in range(n)]

        for target in range(amount + 1):
            dp[0][target] = target // coins[0] if target % coins[0] == 0 else float("inf")

        for ind in range(1, n):
            for target in range(amount + 1):
                notTake = dp[ind - 1][target]
                take = float("inf")
                if coins[ind] <= target:
                    take = 1 + dp[ind][target - coins[ind]]  # same row: coin is reusable
                dp[ind][target] = min(take, notTake)

        return dp[n - 1][amount] if dp[n - 1][amount] != float("inf") else -1

## SOLUTION 3: Space optimized in DP
# Time: O(n*amount) | Space: O(amount) — a single row works since "take" reuses the current row
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        n = len(coins)
        dp = [0 for _ in range(amount + 1)]

        for target in range(amount + 1):
            dp[target] = target // coins[0] if target % coins[0] == 0 else float("inf")

        for ind in range(1, n):
            for target in range(amount + 1):
                notTake = dp[target]
                take = float("inf")
                if coins[ind] <= target:
                    take = 1 + dp[target - coins[ind]]   # reads the value just updated this row
                dp[target] = min(take, notTake)

        return dp[amount] if dp[amount] != float("inf") else -1
```

### Problem 6: Coin Change 2 (Count Ways) : LC 518

[https://leetcode.com/problems/coin-change-ii/description/](https://leetcode.com/problems/coin-change-ii/description/)

Given `coins` (unlimited supply of each) and an `amount`, count the **number of distinct combinations** that make up `amount`. Same unbounded setup as Problem 5 (Coin Change), but combine switches from `min` (fewest coins) back to `+` (count all ways) — the "Count" flavor applied to an unbounded item.

**Recursion tree** (example: `coins = [1, 2]`, `amount = 3`; state `f(ind, target)` = number of ways using `coins[0..ind]` to make `target`):

```
                              f(1, 3)
             pick coin[1]=2 /          \ not-pick
                  same ind ↓              ↓ ind-1
             f(1, 1)                    f(0, 3)
                    |                   3 % 1 == 0 → 1 way
             pick 2? 2<=1 false → take=0
             not-pick → f(0, 1)
             1 % 1 == 0 → 1 way
                    ↓
             f(1,1) = 0 + 1 = 1

        f(1, 3) = take(f(1,1)) + notTake(f(0,3)) = 1 + 1 = 2
        (ways: {1,1,1} and {1,2})
```

**How it connects to the pattern:**

- **State**: `f(ind, target)` — identical to Problem 5.
- **Explore choices**: *not-pick* → `f(ind-1, target)`. *pick* → allowed only if `coin[ind] <= target`, and since coins are reusable it stays on the **same** `ind`: `f(ind, target - coin[ind])` — same unbounded tweak as Problem 5.
- **Combine**: `take + notTake` — back to the "Count" combine from Problem 3, now applied to an unbounded item instead of a 0/1 item.
- **Base case** `ind == 0`: only coin[0] available, reusable → exactly `1` way if `target % coin[0] == 0`, else `0` ways.
- **Space optimization direction**: since coins are unbounded, the 1D array is traversed **forward** (`target` increasing) — same rule as Problem 5's "forward = reuse" trick, because `dp[target - coins[i]]` must read a value **already updated this row**.

### Problem 7: Unbounded Knapsack

[https://takeuforward.org/plus/dsa/problems/unbounded-knapsack?utm=codolio](https://takeuforward.org/plus/dsa/problems/unbounded-knapsack?utm=codolio)

Same setup as 0/1 Knapsack (Problem 4) — items with `weight[i]` and `value[i]`, capacity `W`, maximize total value — but each item can now be used **any number of times**. It's Knapsack's `max` combine, made unbounded like Coin Change (Problem 5).

**Recursion tree** (example: `wt=[1,2]`, `val=[10,15]`, `W=3`; state `f(ind, w)` = max value using `wt[0..ind]` within capacity `w`):

```
                              f(1, 3)
              pick wt[1]=2 /          \ not-pick
                  same ind ↓              ↓ ind-1
             15 + f(1, 1)                f(0, 3)
                    |                    3 // 1 * 10 = 30
             pick 2? 2<=1 false → take=-inf
             not-pick → f(0, 1)
             1 // 1 * 10 = 10
                    ↓
             f(1,1) = max(-inf, 10) = 10

        f(1, 3) = max(15 + f(1,1), f(0,3)) = max(15+10, 30) = 30
        (uses three copies of item 0: weight 1×3, value 10×3)
```

**How it connects to the pattern:**

- **State**: `f(ind, w)` — same shape as 0/1 Knapsack, `w` = remaining capacity.
- **Explore choices**: *not-pick* → `f(ind-1, w)` (unchanged). *pick* → allowed only if `wt[ind] <= w`, and since the item is reusable it stays on the **same** `ind`: `val[ind] + f(ind, w - wt[ind])` — same unbounded tweak as Coin Change.
- **Combine**: `max(pick, notPick)` — the "Optimize" combine from Knapsack, now applied to a reusable item.
- **Base case** `ind == 0`: only item 0 available, reusable → take as many copies as fit: `(w // wt[0]) * val[0]`.
- **Space optimization direction**: unbounded → traverse capacity `w` **forward** (same rule as Coin Change), since `dp[w - wt[i]]` must read a value **already updated this row** to allow reuse.

## DP on Strings

This family covers problems like **Longest Common Subsequence (LCS)**, **Longest Common Substring**, **Shortest Common Supersequence**, **Edit Distance**, and **Distinct Subsequences**. They all compare **two strings** by walking pointers `i` (into `s1`) and `j` (into `s2`).

**The thinking template**

1. **Express everything in terms of two indices**
  - State is usually `f(i, j)` = answer for `s1[0..i]` and `s2[0..j]` (prefixes ending at `i` and `j`).
2. **Explore the match / mismatch choice** at `(i, j)`:
  - **Match** `s1[i] == s2[j]` → both pointers advance together: `1 + f(i-1, j-1)`.
  - **Mismatch** → drop one character from either string and take the best: `max(f(i-1, j), f(i, j-1))` (exact combine depends on the problem — LCS uses `max`, Edit Distance uses `min` + operation cost).
3. **Base case**: `i < 0 or j < 0` → one string is exhausted, usually `return 0` (or a cost proportional to what's left, for Edit Distance).

**Recursion → Tabulation → Space optimization**

- **Memoization**: table size `dp[m][n]`, initialised to `-1`. Recursion indices are the raw string indices (`i`, `j`), can go negative, so bounds checks (`i < 0`) guard the base case directly.
- **Tabulation**: shift everything by `+1` to avoid negative indices — use a `(m+1) x (n+1)` table where `dp[i][j]` represents `f(i-1, j-1)` in recursion terms, and `dp[0][*] = dp[*][0] = 0` **is** the base case (empty prefix).
- **Space optimization**: each row `i` depends only on row `i-1` (`dp[i-1][j-1]`, `dp[i-1][j]`) and the current row (`dp[i][j-1]`) so one 1D array works, but the **diagonal** value `dp[i-1][j-1]` gets overwritten before you read it unless you stash it in a `prev` variable **before** updating `dp[j]`.

```
  Before overwriting dp[j] for row i:
      temp = dp[j]        # save dp[i-1][j] (needed as next iteration's diagonal)
      dp[j] = ...          # now becomes dp[i][j]
      prev = temp          # prev becomes dp[i-1][j], i.e. the diagonal for j+1
```

### Problem 1: Longest Common Subsequence (LCS)

[https://leetcode.com/problems/longest-common-subsequence/?utm=codolio](https://leetcode.com/problems/longest-common-subsequence/?utm=codolio)

Given `text1` and `text2`, find the length of their **longest common subsequence** (characters in relative order, not necessarily contiguous).

**Recursion tree** (example: `text1="ACD"`, `text2="ABD"`; state `f(i,j)` = LCS length of `text1[0..i]`, `text2[0..j]`, target `f(2,2)`):

```
                         f(2,2)  s1[2]='D', s2[2]='D' → match
                            |
                      1 + f(1,1)   s1[1]='C', s2[1]='B' → mismatch
                        /      \
                  f(0,1)        f(1,0)
             s1[0]='A',s2[1]='B'   s1[1]='C',s2[0]='A'
                mismatch              mismatch
                /    \                /    \
           f(-1,1)  f(0,0)       f(0,0)   f(1,-1)
             =0      match=1       match=1    =0
             ↑ f(0,0) reused by both branches → 2D memo

        f(1,1) = max(1, 1) = 1  →  f(2,2) = 1 + 1 = 2   (LCS = "AD")
```

**DP fill (1-indexed table)** :  `dp[i][j]` = LCS length of `text1[0..i-1]`, `text2[0..j-1]`; row/col `0` are the base case (empty prefix ⇒ 0):

```
            ""   A    B    D
         ┌─────────────────────┐
    ""   │  0    0    0    0   │  row 0: base case
    A    │  0    1    1    1   │  'A'=='A' → 1 + dp[0][0]
    C    │  0    1    1    1   │  no match with 'A'/'B'/'D' → carry max(left, up)
    D    │  0    1    1    2 ✓ │  'D'=='D' → 1 + dp[2][2] = 1 + 1 = 2
         └─────────────────────┘
                                    answer = dp[3][3] = 2
```

**How it connects to the pattern:** `f(i, j)` is the two-pointer state, match advances both (`1 + f(i-1,j-1)`), mismatch drops one character from either side and takes `max` — this `max` combine is what distinguishes LCS from, say, Edit Distance's `min` + operation cost.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(m*n) | Space: O(m*n) + O(m+n) stack — state = (i, j), raw string indices
class Solution:
    def f(self, i, j, s1, s2, dp):
        if i < 0 or j < 0:
            return 0                    # one string exhausted

        if dp[i][j] != -1:
            return dp[i][j]             # return cached result

        if s1[i] == s2[j]:
            dp[i][j] = 1 + self.f(i - 1, j - 1, s1, s2, dp)   # match: advance both pointers
        else:
            dp[i][j] = max(self.f(i - 1, j, s1, s2, dp), self.f(i, j - 1, s1, s2, dp))  # drop from either side

        return dp[i][j]

    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)
        dp = [[-1 for _ in range(n)] for _ in range(m)]
        return self.f(m - 1, n - 1, text1, text2, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — shift indices by +1 so row/col 0 = base case
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)
        dp = [[0 for _ in range(n + 1)] for _ in range(m + 1)]  # dp[0][*] = dp[*][0] = 0

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = 1 + dp[i - 1][j - 1]         # match: take the diagonal
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # mismatch: best of dropping either char

        # --- backtrack from dp[m][n] to recover one actual LCS string ---
        i, j = m, n
        lcs_chars = []
        while i > 0 and j > 0:
            if text1[i - 1] == text2[j - 1]:
                # chars match → this position is part of the LCS; record it and step diagonally
                lcs_chars.append(text1[i - 1])
                i -= 1
                j -= 1
            elif dp[i - 1][j] > dp[i][j - 1]:
                # LCS length came from the cell above → text1[i-1] was skipped, move up
                i -= 1
            else:
                # LCS length came from the cell on the left → text2[j-1] was skipped, move left
                j -= 1

        # we walked from the end of both strings, so characters are collected in reverse order
        lcs = "".join(reversed(lcs_chars))

        return dp[m][n]  # length (LeetCode answer); `lcs` holds one valid LCS string

## SOLUTION 3: Space optimized in DP
# Time: O(m*n) | Space: O(n) — one row; `prev` tracks the diagonal before it's overwritten
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)
        dp = [0 for _ in range(n + 1)]  # currently represents row 0 (base case)

        for i in range(1, m + 1):
            prev = 0  # dp[i-1][0], always 0
            for j in range(1, n + 1):
                temp = dp[j]  # save dp[i-1][j] before it's overwritten (needed as next diagonal)
                if text1[i - 1] == text2[j - 1]:
                    dp[j] = 1 + prev            # match: prev holds dp[i-1][j-1]
                else:
                    dp[j] = max(dp[j], dp[j - 1])  # dp[j] is still dp[i-1][j] here
                prev = temp                     # slide the diagonal forward

        return dp[n]
```

### Problem 2: Longest Common Substring

[https://takeuforward.org/data-structure/longest-common-substring-dp-29/](https://takeuforward.org/data-structure/longest-common-substring-dp-29/)

Given `s1` and `s2`, find the length of their **longest common substring** — unlike Problem 1's subsequence, a substring must be **contiguous** (no gaps allowed).

**How this is the same as Problem 1 (LCS):**

- **Same state**: `f(i, j)` / `dp[i][j]` still walks two pointers over `s1` and `s2`.
- **Same match rule**: `s1[i-1] == s2[j-1] → dp[i][j] = 1 + dp[i-1][j-1]` — identical to LCS's match branch, because a matching character always extends whatever run ended right before it.

**What actually changes — only the mismatch branch:**

- **LCS (Problem 1)**: on mismatch, a subsequence can *skip* a character from either string and keep going → `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`. The run doesn't have to be contiguous, so "skipping" is allowed.
- **Substring (Problem 2)**: on mismatch, the **contiguous run breaks** — there's no way to "skip" and stay contiguous, so it must reset to `0` instead of falling back to a neighbor's value: `dp[i][j] = 0`.
- Because a substring can **end anywhere**, the answer is no longer just `dp[m][n]` (bottom-right corner, like LCS) — it's the **maximum value seen anywhere in the whole table**, tracked with a running `maxi` as you fill it.

```
                    LCS (Problem 1)              Substring (Problem 2)
match:         dp[i][j] = 1 + dp[i-1][j-1]   dp[i][j] = 1 + dp[i-1][j-1]   ← same
mismatch:      dp[i][j] = max(up, left)       dp[i][j] = 0                 ← different
answer:        dp[m][n]                       max(dp[i][j] over all i,j)  ← different
```

**DP fill** (example: `s1 = "ABCBDAB"`, `s2 = "BDCAB"` truncated to `s1="ABCB"`, `s2="BDCB"` for a compact table):

```
            ""   B    D    C    B
         ┌─────────────────────────┐
    ""   │  0    0    0    0    0  │  row 0: base case
    A    │  0    0    0    0    0  │  no match with 'B'/'D'/'C'/'B' → reset to 0
    B    │  0    1    0    0    1  │  'B'=='B' → 1 + dp[0][0]; mismatch elsewhere → 0
    C    │  0    0    0    1    0  │  'C'=='C' → 1 + dp[1][2]=1+0=1; else → 0
    B    │  0    1    0    0    2 ✓│  'B'=='B' twice in a row → 1 + dp[3][3]=1+1=2
         └─────────────────────────┘
                      answer = max over table = 2   (substring "CB")
```

Note how a mismatch **resets to `0**` (never falls back to `max(up, left)` like LCS does) — that reset is the entire difference between these two problems.

```python
## SOLUTION 1: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — same table shape as LCS; only the mismatch rule differs
class Solution:
    def longestCommonSubstr(self, s1, s2):
        m = len(s1)
        n = len(s2)
        dp = [[0 for _ in range(n + 1)] for _ in range(m + 1)]  # dp[0][*] = dp[*][0] = 0
        maxi = 0  # track best substring length seen anywhere, not just dp[m][n]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s1[i - 1] == s2[j - 1]:
                    dp[i][j] = 1 + dp[i - 1][j - 1]   # same as LCS: extend the diagonal run
                else:
                    dp[i][j] = 0                        # unlike LCS: contiguous run breaks, reset

                maxi = max(maxi, dp[i][j])               # substring can end at any (i, j)

        return maxi

## SOLUTION 2: Space optimized in DP
# Time: O(m*n) | Space: O(n) — one row; same diagonal-tracking trick as LCS Solution 3
class Solution:
    def longestCommonSubstr(self, s1, s2):
        m = len(s1)
        n = len(s2)
        dp = [0 for _ in range(n + 1)]  # currently represents row 0 (base case)
        maxi = 0

        for i in range(1, m + 1):
            prev = 0  # dp[i-1][0], always 0
            for j in range(1, n + 1):
                temp = dp[j]  # save dp[i-1][j] before it's overwritten (needed as next diagonal)
                if s1[i - 1] == s2[j - 1]:
                    dp[j] = 1 + prev   # match: prev holds dp[i-1][j-1]
                else:
                    dp[j] = 0           # mismatch: reset, no fallback to neighbors
                maxi = max(maxi, dp[j])
                prev = temp             # slide the diagonal forward

        return maxi
```

### Problem 3: Longest Palindromic Subsequence

[https://leetcode.com/problems/longest-palindromic-subsequence/?utm=codolio](https://leetcode.com/problems/longest-palindromic-subsequence/?utm=codolio)

No new pattern needed here — this is **Problem 1 (LCS) in disguise**.

A palindrome reads the same forwards and backwards. So the longest palindromic subsequence of `s` is just the **longest subsequence common to `s` and `reverse(s)**`:

```
longestPalindromicSubsequence(s) = LCS(s, reverse(s))
```

Reuse any of Problem 1's three solutions unchanged — just call them with `s` and `s[::-1]` as the two input strings, and the returned length is the answer.

### Problem 4: Minimum Insertion Steps to Make a String Palindrome

[https://leetcode.com/problems/minimum-insertion-steps-to-make-a-string-palindrome/](https://leetcode.com/problems/minimum-insertion-steps-to-make-a-string-palindrome/)

One more step on top of Problem 3 (LPS) — no new DP needed here either.

**The insight:** any character that's already part of the **longest palindromic subsequence** doesn't need an insertion — it's already "mirrored" correctly. Every character **outside** the LPS needs exactly one inserted partner to pair it up. So:

```
minInsertions(s) = len(s) - LPS(s)
```

```
  s = "mbadm"          LPS = "mam"  (length 3)
        m b a d m
        ↑     ↑ ↑        3 chars already form a palindrome
          ↑ ↑           2 chars ("b", "d") are "unmatched"

  answer = len(s) - LPS(s) = 5 - 3 = 2
  (insert 2 chars to mirror 'b' and 'd', e.g. "mbdadbm")
```

So this reduces to **Problem 3 (LPS)**, which itself reduces to **Problem 1 (LCS)** — the whole chain is: compute `LCS(s, reverse(s))` to get `LPS(s)`, then subtract from `len(s)`.

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        lps = self.longestCommonSubsequence(s, s[::-1])  # reuse Problem 1 / 3 as-is
        return n - lps
```

### Problem 5: Delete Operation for Two Strings (LC 583)

[https://leetcode.com/problems/delete-operation-for-two-strings/](https://leetcode.com/problems/delete-operation-for-two-strings/)

Another one-liner on top of **Problem 1 (LCS)**. Chars in the LCS are already shared — only the leftover chars in each string need deleting:

```
minDeletions(word1, word2) = len(word1) + len(word2) - 2 * LCS(word1, word2)
```

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:

```

### Problem 6: Shortest Common Supersequence (LC 1092)

[https://leetcode.com/problems/shortest-common-supersequence/](https://leetcode.com/problems/shortest-common-supersequence/)

Same LCS foundation, but this time we must return the **actual string**, not just a length — so a length formula alone (like Problems 3–5) isn't enough; we need to **backtrack through the LCS table**.

**Length insight (same family as Problem 5):** each LCS character is shared, so it should appear only **once** in the merged string. Every other character from both strings must appear too:

```
len(supersequence) = len(str1) + len(str2) - LCS(str1, str2)
```

**Building the string:** walk the LCS `dp` table from `(m, n)` back to `(0, 0)` (same traversal as Problem 1's backtracking):

```
  if str1[i-1] == str2[j-1]:      # common char → take it once, move diagonally
      result.append(str1[i-1]); i -= 1; j -= 1
  elif dp[i-1][j] > dp[i][j-1]:   # str1's char wasn't part of the LCS here → keep it
      result.append(str1[i-1]); i -= 1
  else:                           # str2's char wasn't part of the LCS here → keep it
      result.append(str2[j-1]); j -= 1

  # then dump whatever remains of either string (one of i, j hits 0 first)
```

This is the **same backtracking logic** as reconstructing the LCS itself (Problem 1, Solution 2) — the only change is that on a **mismatch** we keep the character instead of discarding it, since the supersequence needs every character from both strings, common or not.

```python
class Solution:
    def shortestCommonSupersequence(self, str1: str, str2: str) -> str:
        m, n = len(str1), len(str2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if str1[i - 1] == str2[j - 1]:
                    dp[i][j] = 1 + dp[i - 1][j - 1]
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        i, j = m, n
        merged = []
        while i > 0 and j > 0:
            if str1[i - 1] == str2[j - 1]:
                merged.append(str1[i - 1])   # common char: keep once
                i -= 1
                j -= 1
            elif dp[i - 1][j] > dp[i][j - 1]:
                merged.append(str1[i - 1])   # str1's leftover char: keep
                i -= 1
            else:
                merged.append(str2[j - 1])   # str2's leftover char: keep
                j -= 1

        while i > 0:               # dump remaining prefix of str1
            merged.append(str1[i - 1]); i -= 1
        while j > 0:                # dump remaining prefix of str2
            merged.append(str2[j - 1]); j -= 1

        return "".join(reversed(merged))  # built back-to-front, so reverse
```

### Problem 7: Distinct Subsequences (New Pattern)

[https://leetcode.com/problems/distinct-subsequences/description/?utm=codolio](https://leetcode.com/problems/distinct-subsequences/description/?utm=codolio)

Given `s` and `t`, count the number of **distinct subsequences of `s` that equal `t**`. This breaks from the LCS-style problems above — it's no longer symmetric between the two strings. `t` must be matched **in full and in order**; only `s` gets to "skip" characters.

**Recursion tree** (example: `s = "babgbag"` truncated to `s = "bag"`, `t = "bg"`; state `f(i, j)` = ways to form `t[0..j]` using `s[0..i]`, target `f(2, 1)`):

```
                         f(2, 1)   s[2]='g', t[1]='g' → match
                    match /   \ also skip s[2]
              f(1, 0)          f(1, 1)   s[1]='a', t[1]='g' → mismatch, must skip
              s[1]='a'≠t[0]='b'      |
              → f(0, 0)            f(0, 1)   t not fully matched, s exhausted → 0
              s[0]='b'==t[0]='b'
              → f(-1,-1) + f(-1,0)
                 =1        =0
                 ↓
              f(0,0) = 1 + 0 = 1  →  f(1,0) = 1

        f(2, 1) = f(1, 0) + f(1, 1) = 1 + 0 = 1   (only "bg" from positions 0,2)
```

**How this differs from LCS-style problems:**

- **Match** `s[i] == t[j]`: two choices contribute — **use** `s[i]` to match `t[j]` (`f(i-1, j-1)`) **or skip** `s[i]` and still try to match `t[j]` later (`f(i-1, j)`). Both are added, since we're **counting** all distinct ways: `f(i,j) = f(i-1,j-1) + f(i-1,j)`.
- **Mismatch**: only one option — skip `s[i]`, since `t[j]` can't be matched by it: `f(i,j) = f(i-1,j)`. Unlike LCS, there's no "skip `t[j]` instead" branch — `t` is the fixed target, `s` is the only string allowed to shrink.
- **Base cases**: `j < 0` (all of `t` matched) → `1` way. `i < 0` (ran out of `s`, `t` not fully matched) → `0` ways.

**DP fill (1-indexed table)** — `dp[i][j]` = ways to form `t[0..j-1]` from `s[0..i-1]`; column `0` is the base case (empty `t` ⇒ always `1` way). Worked example: `s = "babgbag"`, `t = "bag"` (LeetCode's own example, answer `5`):

```
             ""   b    a    g
          ┌───────────────────────┐
    ""    │  1    0    0    0     │  row 0: can't form non-empty t from empty s
    b     │  1    1    0    0     │  'b'=='b' → dp[0][0]+dp[0][1] = 1+0 = 1
    a     │  1    1    1    0     │  'a'=='a' → dp[1][1]+dp[1][2] = 1+0 = 1
    b     │  1    2    1    0     │  'b'=='b' → dp[2][0]+dp[2][1] = 1+1 = 2
    g     │  1    2    1    1     │  'g'=='g' → dp[3][2]+dp[3][3] = 1+0 = 1
    b     │  1    3    1    1     │  'b'=='b' → dp[4][0]+dp[4][1] = 1+2 = 3
    a     │  1    3    4    1     │  'a'=='a' → dp[5][1]+dp[5][2] = 3+1 = 4
    g     │  1    3    4    5 ✓   │  'g'=='g' → dp[6][2]+dp[6][3] = 4+1 = 5
          └───────────────────────┘
                                      answer = dp[7][3] = 5
```

`s = "babgbag"` has three `b`s (positions 0, 2, 4), two `a`s (positions 1, 5), and two `g`s (positions 3, 6). Any `(b, a, g)` triple with increasing positions spells `"bag"` — there are `5` such valid triples (not all `3×2×2 = 12` combos, since the chosen `a` and `g` must come *after* the chosen `b`), matching `dp[7][3] = 5`.

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(m*n) | Space: O(m*n) + O(m) stack — state = (i, j), raw string indices
class Solution:
    def f(self, i, j, s, t, dp):
        if j < 0:
            return 1                     # all of t matched → 1 way
        if i < 0:
            return 0                      # ran out of s, t not fully matched

        if dp[i][j] != -1:
            return dp[i][j]               # return cached result

        if s[i] == t[j]:
            # use s[i] to match t[j], OR skip s[i] and match t[j] with an earlier char
            dp[i][j] = self.f(i - 1, j - 1, s, t, dp) + self.f(i - 1, j, s, t, dp)
        else:
            dp[i][j] = self.f(i - 1, j, s, t, dp)  # s[i] can't help, must skip it

        return dp[i][j]

    def numDistinct(self, s: str, t: str) -> int:
        m = len(s)
        n = len(t)
        dp = [[-1 for _ in range(n)] for _ in range(m)]
        return self.f(m - 1, n - 1, s, t, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — shift indices by +1; column 0 = base case
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m = len(s)
        n = len(t)
        dp = [[0 for _ in range(n + 1)] for _ in range(m + 1)]

        for i in range(m + 1):
            dp[i][0] = 1                 # empty t is always formed exactly 1 way

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i - 1] == t[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]  # use s[i-1] OR skip it
                else:
                    dp[i][j] = dp[i - 1][j]                      # must skip s[i-1]

        return dp[m][n]

## SOLUTION 3: Space optimized in DP
# Time: O(m*n) | Space: O(n) — only the previous row is needed
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m = len(s)
        n = len(t)
        dp = [0 for _ in range(n + 1)]
        dp[0] = 1                        # empty t, base case for row 0

        for i in range(1, m + 1):
            curr = [0] * (n + 1)
            curr[0] = 1                  # empty t is always formed 1 way, every row
            for j in range(1, n + 1):
                if s[i - 1] == t[j - 1]:
                    curr[j] = dp[j - 1] + dp[j]  # use s[i-1] OR skip it (dp = previous row)
                else:
                    curr[j] = dp[j]               # must skip s[i-1]
            dp = curr                     # current row becomes previous row

        return dp[n]
```

### Problem 8: Edit Distance

[https://leetcode.com/problems/edit-distance/](https://leetcode.com/problems/edit-distance/)

Given `word1` and `word2`, find the **minimum number of operations** (insert, delete, or replace a character) to convert `word1` into `word2`. Same `f(i, j)` two-pointer state as LCS / Distinct Subsequences, but now both strings can be mutated and the combine is `min` over three edits.

**Recursion tree** (example: `word1 = "horse"`, `word2 = "ros"` truncated to `word1 = "ho"`, `word2 = "ro"`; state `f(i, j)` = min edits to turn `word1[0..i]` into `word2[0..j]`, target `f(1, 1)`):

```
                         f(1, 1)   'o'=='o' → match, no cost
                            |
                      f(0, 0)   'h'!='r' → try 3 edits
               delete /  insert |  replace \
          1+f(-1,0)=1   1+f(0,-1)=1   1+f(-1,-1)=1
                            ↓
                      f(0,0) = 1  →  f(1,1) = 1
                      (replace 'h'→'r'; 'o' already matches)
```

**How it connects to the pattern:**

- **Match** `word1[i] == word2[j]`: characters already agree → no edit, just advance both: `f(i-1, j-1)`.
- **Mismatch**: three options, each costs `+1`:
  - **Delete** `word1[i]` → `1 + f(i-1, j)`
  - **Insert** `word2[j]` into `word1` → `1 + f(i, j-1)`
  - **Replace** `word1[i]` with `word2[j]` → `1 + f(i-1, j-1)`
  - Take `min` of the three.
- **Base cases**: `i < 0` → need `j+1` inserts to build the remaining `word2`. `j < 0` → need `i+1` deletes to wipe the remaining `word1`.

**DP fill (1-indexed)** — `dp[i][j]` = min edits to turn `word1[0..i-1]` into `word2[0..j-1]`; row/col `0` are the base cases. Worked example: `word1 = "horse"`, `word2 = "ros"` (answer `3`):

```
             ""   r    o    s
          ┌──────────────────────┐
    ""    │  0    1    2    3    │  empty → word2: j inserts
    h     │  1    1    2    3    │  'h'!='r' → 1+min(up=1, left=1, diag=0) = 1 (replace)
    o     │  2    2    1    2    │  'o'=='o' → diag = 1
    r     │  3    2    2    2    │  'r'=='r' → diag = 2
    s     │  4    3    3    2    │  's'=='s' → diag = 2
    e     │  5    4    4    3 ✓  │  answer = dp[5][3] = 3
          └──────────────────────┘
                      (e.g. horse → rorse → rose → ros)
```

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(m*n) | Space: O(m*n) + O(m+n) stack — state = (i, j)
class Solution:
    def f(self, i, j, s1, s2, dp):
        if i < 0:
            return j + 1                 # insert remaining chars of s2
        if j < 0:
            return i + 1                 # delete remaining chars of s1

        if dp[i][j] != -1:
            return dp[i][j]

        if s1[i] == s2[j]:
            dp[i][j] = self.f(i - 1, j - 1, s1, s2, dp)  # match: no cost
        else:
            delete = self.f(i - 1, j, s1, s2, dp)
            insert = self.f(i, j - 1, s1, s2, dp)
            replace = self.f(i - 1, j - 1, s1, s2, dp)
            dp[i][j] = 1 + min(delete, insert, replace)

        return dp[i][j]

    def minDistance(self, word1: str, word2: str) -> int:
        m = len(word1)
        n = len(word2)
        dp = [[-1 for _ in range(n)] for _ in range(m)]
        return self.f(m - 1, n - 1, word1, word2, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — row/col 0 = base cases (inserts / deletes)
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m = len(word1)
        n = len(word2)
        dp = [[0 for _ in range(n + 1)] for _ in range(m + 1)]

        for i in range(m + 1):
            dp[i][0] = i                 # delete all of word1[0..i-1]
        for j in range(n + 1):
            dp[0][j] = j                 # insert all of word2[0..j-1]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]              # match: no cost
                else:
                    dp[i][j] = 1 + min(
                        dp[i - 1][j],      # delete
                        dp[i][j - 1],      # insert
                        dp[i - 1][j - 1],  # replace
                    )

        return dp[m][n]

## SOLUTION 3: Space optimized in DP
# Time: O(m*n) | Space: O(n) — one previous row; diagonal needed on match/replace
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m = len(word1)
        n = len(word2)
        dp = [j for j in range(n + 1)]   # row 0: j inserts

        for i in range(1, m + 1):
            curr = [0] * (n + 1)
            curr[0] = i                  # delete all of word1[0..i-1]
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    curr[j] = dp[j - 1]  # match: diagonal = previous row's left cell
                else:
                    curr[j] = 1 + min(
                        dp[j],           # delete (from previous row)
                        curr[j - 1],     # insert (from current row)
                        dp[j - 1],       # replace (diagonal)
                    )
            dp = curr

        return dp[n]
```

### Problem 9: Wildcard Matching

[https://leetcode.com/problems/wildcard-matching/](https://leetcode.com/problems/wildcard-matching/)

Given string `s` and pattern `p` containing `?` (matches any **one** char) and `*` (matches any **sequence**, including empty), return whether `p` matches the **entire** `s`. Same `f(i, j)` two-pointer state as Edit Distance / Distinct Subsequences, but the combine is a **boolean** (`OR` / feasibility) driven by the wildcard rules.

**How the wildcards map to the pattern:**

| Pattern char | Meaning | Transition |
| ------------ | ------- | ---------- |
| letter / `?` | match exactly one char | `f(i-1, j-1)` if chars match (or `?`) |
| `*` | match empty **or** match one more char of `s` and stay on `*` | `f(i, j-1) OR f(i-1, j)` |
| mismatch     | no match | `False` |

**Base cases:**
- `i < 0 and j < 0` → both exhausted → `True`
- `j < 0 and i >= 0` → pattern done, string left → `False`
- `i < 0 and j >= 0` → string done, pattern left → `True` only if the remaining pattern is all `*`s (each can match empty)

**DP fill (1-indexed)** — `dp[i][j]` = does `p[0..j-1]` match `s[0..i-1]`? Worked example: `s = "adceb"`, `p = "*a*b"` (answer `True`):

```
             ""   *    a    *    b
          ┌──────────────────────────┐
    ""    │  T    T    F    F    F   │  * can match empty → dp[0][1]=T; 'a' can't match empty
    a     │  F    T    T    T    F   │  'a'=='a' → diag; * absorbs/forwards
    d     │  F    T    F    T    F   │  * at j=1/j=3 absorbs 'd'
    c     │  F    T    F    T    F   │
    e     │  F    T    F    T    F   │
    b     │  F    T    F    T    T ✓ │  'b'=='b' → diag from dp[4][3]=T
          └──────────────────────────┘
                                      answer = dp[5][4] = True
```

```python
## SOLUTION 1: Recursion with Memoization
# Time: O(m*n) | Space: O(m*n) + O(m+n) stack — state = (i, j)
class Solution:
    def f(self, i, j, s, p, dp):
        if i < 0 and j < 0:
            return True                  # both exhausted
        if j < 0 and i >= 0:
            return False                 # pattern done, string leftover
        if i < 0 and j >= 0:
            # string done: remaining pattern must be all '*' (each matches empty)
            for k in range(j + 1):
                if p[k] != "*":
                    return False
            return True

        if dp[i][j] != -1:
            return dp[i][j]

        if s[i] == p[j] or p[j] == "?":
            dp[i][j] = self.f(i - 1, j - 1, s, p, dp)  # match one char
        elif p[j] == "*":
            # '*' matches empty (skip '*') OR matches s[i] and stays on '*'
            dp[i][j] = self.f(i, j - 1, s, p, dp) or self.f(i - 1, j, s, p, dp)
        else:
            dp[i][j] = False             # hard mismatch

        return dp[i][j]

    def isMatch(self, s: str, p: str) -> bool:
        m = len(s)
        n = len(p)
        dp = [[-1 for _ in range(n)] for _ in range(m)]
        return self.f(m - 1, n - 1, s, p, dp)

## SOLUTION 2: Time optimized using DP (2D Tabulation)
# Time: O(m*n) | Space: O(m*n) — row/col 0 = base cases
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m = len(s)
        n = len(p)
        dp = [[False for _ in range(n + 1)] for _ in range(m + 1)]
        dp[0][0] = True                  # empty matches empty

        for j in range(1, n + 1):
            if p[j - 1] == "*":
                dp[0][j] = dp[0][j - 1]  # leading '*'s can match empty string

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i - 1] == p[j - 1] or p[j - 1] == "?":
                    dp[i][j] = dp[i - 1][j - 1]
                elif p[j - 1] == "*":
                    dp[i][j] = dp[i - 1][j] or dp[i][j - 1]  # absorb char OR match empty
                # else: stays False

        return dp[m][n]

## SOLUTION 3: Space optimized in DP
# Time: O(m*n) | Space: O(n) — one row; `prev` tracks the diagonal before overwrite
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m = len(s)
        n = len(p)
        dp = [False for _ in range(n + 1)]
        dp[0] = True

        for j in range(1, n + 1):
            if p[j - 1] == "*":
                dp[j] = dp[j - 1]        # leading '*'s match empty

        for i in range(1, m + 1):
            prev = dp[0]                 # diagonal for j=1
            dp[0] = False                # non-empty s never matches empty p
            for j in range(1, n + 1):
                temp = dp[j]             # save dp[i-1][j] before overwrite
                if s[i - 1] == p[j - 1] or p[j - 1] == "?":
                    dp[j] = prev         # match: take diagonal
                elif p[j - 1] == "*":
                    dp[j] = dp[j] or dp[j - 1]  # absorb (old dp[j]) OR empty (dp[j-1])
                else:
                    dp[j] = False
                prev = temp              # slide diagonal forward

        return dp[n]
```
