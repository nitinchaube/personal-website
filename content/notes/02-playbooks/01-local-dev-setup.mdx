A repeatable checklist for getting a new machine ready to ship code.

## 1. The bare essentials

- [ ] Install Homebrew
- [ ] `brew install git gh" node pnpm uv ripgrep fzf bat`
- [ ] Install Cursor + sign in
- [ ] Install iTerm2 + set as default

## 2. Shell

```bash
chsh -s /bin/zsh
curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh | sh
```

Then drop my dotfiles into `~/.config/` and `source ~/.zshrc`.

## 3. Verify

```bash
git --version
node --version
gh auth status
```

If any of those fail, fix before moving on — don't accumulate setup debt.
