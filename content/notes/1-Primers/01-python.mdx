## Comprehensions

```python
squares = [x * x for x in range(10)]
lookup = {k: v for k, v in pairs}
unique = {x.lower() for x in words}
```

## Dunder I always forget

| Dunder | Purpose |
| --- | --- |
| `__post_init__` | Run after `@dataclass` `__init__` |
| `__class_getitem__` | Generic subscript on the class itself |
| `__set_name__` | Descriptor learns the attribute name it's bound to |
| `__init_subclass__` | Hook into every subclass at class-creation time |

## Pattern matching

```python
match shape:
    case Circle(radius=r):
        return 3.14 * r * r
    case Rectangle(width=w, height=h):
        return w * h
    case _:
        raise ValueError("unknown shape")
```

## Notes to self

- Default mutable args are a footgun; use `None` and assign inside the body.
- `pathlib.Path` over string paths, always.
- For numeric work, prefer `numpy` operations to Python-level loops — by 1–2 orders of magnitude.
